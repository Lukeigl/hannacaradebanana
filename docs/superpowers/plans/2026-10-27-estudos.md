# Estudos de anatomia Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Entregar página de estudo utilizável, protegida por criptografia e com conteúdo revisado.
**Architecture:** Shell estático desbloqueia HTML cifrado; dados de estudo e imagens residem apenas no pacote. Funções puras de quiz e persistência independente da interface.
**Tech Stack:** HTML, CSS, JavaScript, Web Crypto, Node test runner.
**Spec:** docs/superpowers/specs/2026-10-27-estudos-design.md

## Global Constraints
- Nenhuma senha ou conteúdo legível em Git.
- Manter o presente intacto.
- Referência curricular 3ª edição; identificar limites de consulta.
- Conteúdo autoral em português e atribuições das ilustrações.

## Review Focus
- Senha ou usuário errados, pacote alterado: bloquear abertura.
- Storage indisponível: continuar na memória.
- Simulado incompleto: contabilizar não respondidas, sem inflar acertos.
- Tela de 390 px: textos/legendas/botões sem corte.
- Sem conta/servidor: não apresentar como autenticação de servidor.
